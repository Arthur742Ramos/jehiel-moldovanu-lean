# Jehiel–Moldovanu Impossibility in Lean 4

Lean 4 / Mathlib formalization of the Jehiel–Moldovanu impossibility theorem
(2001): with multidimensional types and interdependent valuations, no mechanism
is simultaneously ex post efficient, Bayesian incentive compatible, and budget
balanced. The impossibility flip side of the AGV possibility result.

## Status

M0 research note complete. See `M0-research-note.md` for the finite
formalization plan (2 agents, 2D binary types, interdependent values, 4-cycle
congruence argument).
